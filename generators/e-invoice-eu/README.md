# e-invoice-eu (gflohr/e-invoice-eu) — not in the matrix yet

Like horstoeko/zugferd and drafthorse, e-invoice-eu (inspected at commit 9948d0f) does not compute
invoice totals: the integrator supplies every amount. Running it with the reference totals would only
test serialisation, so it was left out of the current matrix. A driver is welcome; see CONTRIBUTING.md.
